# mvsolver - 「Minesweeper Variants」を自動で解くプログラム

## 概要
Steamで公開されているゲーム「Minesweeper Variants」を、プログラム実行後、画像の判別と画面のクリックを自動で行いゲームを解きます。
動作に甘い点が多く、自分の環境でしか試していないので下記の注意点をお読みください。

## 使い方
https://rigarenu.main.jp/blog/game/?p=884も参照
「Minesweeper Variants」を起動し、解きたいレベルを選択した後、盤面が表示されている状態でこのプログラムを実行します。
同レベル内なら、解き終わった後自動で次のステージに移動し解き続けます。
ループ中は止まりません。どうしても止めたい場合は「Alt + Tab」で隙を見てウィンドウを切り替え、実行環境ごとの停止コマンドを実行してください。

## 注意点
1. マウス操作を自動で行うので、初めて実行する際はループ回数を少なめにし、動作するかどうかを確認してみてください。
2. 「Minesweeper Variants」の画面はすべて画面に映してください。一部が隠れていたりすると動作しません。
3. 画面のサイズを変更するとうまく動作しません。起動時のサイズから変更しないようにしてください。フルスクリーンもNG。
4. 設定でヒントを有効にしてください。
5. 設定でフライジャルスターをオフにしないとパーフェクトクリアになりません。
6. 言語は日本語のみに対応しています。
7. 変なループに入ってしまう場合は上記の方法で無理やり停止させ、クリック後の待機時間を長めにしてみてください。
