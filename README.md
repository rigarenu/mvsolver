# mvsolver - 「Minesweeper Variants」を自動で解くプログラム

## 概要
Steamで公開されているゲーム「Minesweeper Variants」を、プログラム実行後、画像の判別と画面のクリックを自動で行いゲームを解きます。
動作に甘い点が多く、自分の環境でしか試していないので下記の注意点をお読みください。

## 使い方
https://rigarenu.main.jp/blog/game/?p=884

左上の設定からゲームモードを「ノーマルモード」にし、言語を「英語」にして下さい。またショートカットキーはデフォルト設定にしてください。

1ステージのみを繰り返し解きたい場合は、解きたいレベルを選択した後、盤面が表示されている状態で「solve()」を実行します。同レベル内なら、解き終わった後自動で次のステージに移動し解き続けます。

全ステージを解きたい場合はステージ選択画面で「solveAll()」を実行します。非常に時間がかかるので、まずは少なめの問題数で試してください。アンロックされていないステージは実行できないので注意。

ループ中は止まりません。止めたい場合は「Alt + Tab」で隙を見てウィンドウを切り替え、実行環境ごとの停止コマンドを実行してください。

## 注意点
1. マウス、キーボード操作を自動で行うので、初めて実行する際はループ回数を少なめにし、動作するかどうかを確認してみてください。
2. 「Minesweeper Variants」の画面はすべて画面に映してください。一部が隠れていたりすると動作しません。
3. 画面のサイズを変更するとうまく動作しません。起動時のサイズから変更しないようにしてください。フルスクリーンもNG。
4. 設定でフライジャルスターをオフにしないとパーフェクトクリアになりません。
